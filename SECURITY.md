# Security Policy

## Supported Versions

Security fixes are applied to the current `develop` branch and included in the
next release from `main`.

## Reporting a Vulnerability

Please **do not open a public issue** for a suspected vulnerability.

Report it privately through GitHub Security Advisories for this repository:
<https://github.com/claudioed/workforce-management/security/advisories/new>

Include a clear description, affected component/version, reproduction steps or
proof of concept, potential impact, and any suggested remediation. We will
acknowledge receipt within 7 days, keep you informed of progress, and coordinate
disclosure after a fix is available.

For non-sensitive defects, use the regular issue tracker.
